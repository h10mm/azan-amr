# الأذان — Al-Azan (تطبيق أذان ومواقيت صلاة مفتوح المصدر)

<div dir="rtl">

تطبيق إسلامي خيري ومفتوح المصدر لحساب مواقيت الصلاة والأذان والقبلة والأذكار والتقويم الهجري والميلادي والقبطي — **يعمل محلياً بالكامل بدون إنترنت، وبدون إعلانات، وبدون تتبع أو جمع أي بيانات شخصية.**

### ✨ أبرز المميزات
- **حساب دقيق لمواقيت الصلاة محلياً (100% بدون إنترنت):** يعتمد على مكتبة `batoulapps.adhan` مع اقتراح تلقائي لطريقة الحساب الرسمية حسب بلدك (الهيئة المصرية، أم القرى، رابطة العالم الإسلامي، ديانت، وغيرها).
- **مجموعة ودجات موحّدة للشاشة الرئيسية (8 ودجات متجاوبة):**
  - رزمانة الحائط اليومية (النتيجة الورقية الكلاسيكية مع التاريخ الهجري والميلادي والقبطي وحكمة اليوم بخط النسخ).
  - التقويم المكتبي المتطور (يتكيف تلقائياً بين الأفقي والمربع).
  - المواقيت والتقويم المدمج، القرص الدائري، البطاقة المربعة (بوضع شفاف كامل)، الشريط النحيف، محراب المسجد، والكبسولة الروحية الذكية.
- **الكبسولة الروحية الذكية والتذكيرات:** تذكير ذكي بلحظات العبادة (بين الأذان والإقامة، معقبات الصلاة، الضحى، قيام الليل، صيام النوافل، سورة الكهف وسورة الملك).
- **الأذكار والمسبحة الإلكترونية:** أذكار الصباح والمساء والنوم وما بعد الصلاة، مع مسبحة متطورة تدعم العدّ الصوتي، أزرار الصوت، والمسبحة العائمة.
- **التقويم المزدوج والقبلة:** تقويم هجري/ميلادي تفاعلي بالمناسبات الإسلامية والأيام البيض، وبوصلة قبلة دقيقة.
- **دعم 15 لغة و3 سمات فاخرة:** الفاتح الكلاسيكي، الأسود الداكن (AMOLED)، والأزرق الكحلي الليلي (Midnight Blue).

### 🙏 حفظ الحقوق والمصدر الأصلي
تم تطوير هذا التطبيق وبناء إضافاته اعتماداً على المشروع مفتوح المصدر **[Al-Azan Compose](https://github.com/meypod/al-azan-compose)** مع حفظ كامل الحقوق والفضل لمطوريه الأصليين، جزاهم الله خيراً.

1. استنسخ المستودع:
   ```bash

   ```
2. افتح المشروع في **Android Studio** (يدعم JDK 11+ و Android SDK 36/37).
3. قم ببناء النسخة التجريبية وتشغيلها:
   ```bash

   ```

## English Overview

**Al-Azan** is a free, charitable, open-source Android prayer times and Islamic companion app built with **Jetpack Compose** and **Material 3**. It works **100% offline**, with **no ads, no analytics, and no personal data collection**.

### ✨ Key Features
- **100% Offline Prayer Times:** Astronomical calculation via `batoulapps.adhan` with automatic calculation method selection by country.
- **8 Unified, Responsive Home Screen Widgets:** Daily Wall Calendar (Nateega), Adaptive Desk Calendar, Compact Prayer Bar, Circular & Square Next-Prayer Dials (including true transparent mode), Slim Bar, Mosque Arch, and Smart Spiritual Pill.
- **Smart Spiritual Capsule & Reminders:** Timely reminders for Duha, Qiyam, Adhkar, Surah Al-Kahf, Surah Al-Mulk, and Sunnah fasting days.
- **Adhkar & Digital Tasbih:** Categorized prophetic Adhkar plus a feature-rich Tasbih counter (voice counting, volume-key counting, floating bubble).
- **Dual Hijri/Gregorian Calendar & Qibla Compass:** Interactive monthly calendar with Islamic occasions & White Days, plus accurate Qibla direction.
- **15 Languages & 3 Themes:** Classic Light, AMOLED Dark, and Midnight Blue.
